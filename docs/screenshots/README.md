# Offline náhľady klienta

Tieto PNG sú offline render skutočných view funkcií klienta s výsledkami syntetických PDF. Nie sú screenshoty nasadenej verejnej služby. Browser end-to-end test ostal zablokovaný politikou prostredia. Detaily: `../VERIFICATION.md` a `../layout-results.json`.

`*-desktop-offline.png`: šírka 1440 px. Ostatné sú šírky 360, 390, 430 a 932 px. Široké tabuľky sa posúvajú v rámci svojho kontajnera.
